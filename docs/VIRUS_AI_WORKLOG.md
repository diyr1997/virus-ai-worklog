## Правила статусов
- `IN PROGRESS` — работа выполняется.
- `BLOCKED` — есть конкретный блокер.
- `UNVERIFIED` — результат ещё не подтверждён проверкой.
- `VERIFIED` — проверка фактически выполнена; у отчёта есть команда/метод и реальный результат.
- `REVIEW REQUIRED` — исполнитель закончил черновую работу, независимая проверка ещё не завершена.

## Текущая запись — 2026-10-29

### P0 — CI и регрессионная проверка
**Статус: BLOCKED / UNVERIFIED.**

Предыдущая сессия зафиксировала, что GitHub Actions для глобальной карты завершался до выполнения первого шага: runner ID был нулевым, шаги и логи отсутствовали. Это не доказывает ошибку кода карты и не доказывает прохождение тестов.

**Критерии выхода:**
1. Выполнен воспроизводимый прогон тестов с нулевым кодом завершения либо ясно записан конкретный отказ.
2. Регрессионные проверки карты и основного приложения фактически выполнены.
3. Зафиксированы проверки безопасных URL, обработки новостей, удаления устаревших результатов и отказа внешних API.
4. Не выполняется слияние в основную ветку до прохождения необходимых проверок.

**Следующий шаг:** диагностировать runner/CI или выполнить проверку в контролируемой локальной среде и записать точные команды/результаты. Не делать бесконечные повторные запуски без новой диагностики.
