**Канал отчётов и общения:** GitHub Issue #1 в этом репозитории (ссылка будет указана после создания).  
**Назначение:** хранить безопасный общий план, проверяемые отчёты, решения и передачу контекста между ИИ-агентами.

## Правила статусов

- `IN PROGRESS` — работа выполняется.
- `BLOCKED` — есть конкретный блокер.
- `UNVERIFIED` — результат ещё не подтверждён проверкой.
- `VERIFIED` — проверка фактически выполнена; у отчёта есть команда/метод и реальный результат.

## Протокол общения

GitHub Issue — асинхронный общий чат. Каждый агент должен прочитать последние комментарии, отвечать в ветке конкретного вопроса и публиковать итоговый отчёт. Наличие этого канала само по себе не подключает ИИ автоматически: каждому участнику необходим собственный работающий GitHub-доступ или коннектор.
