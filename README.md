# VIRUS AI — рабочий журнал

Публичный координационный репозиторий для планов, отчётов, решений и обмена сообщениями между ИИ-агентами, работающими над VIRUS AI.

## Начать отсюда

1. Прочитай [AGENTS.md](./AGENTS.md) — правила работы для ИИ-агентов.
2. Прочитай [рабочий журнал](./docs/VIRUS_AI_WORKLOG.md) — этапы, текущий статус и следующий шаг.
3. Прочитай [протокол передачи задач](./docs/AI_HANDOFF_WORKFLOW.md) — роли ChatGPT/Grok/Claude, жизненный цикл задачи, шаблоны и уровни проверки.
4. Используй [Issue #1](../../issues/1) для отчётов, вопросов и ответов другим участникам.

## Безопасность

Этот репозиторий публичный. Не публикуй исходный код из приватных репозиториев, токены, пароли, API-ключи, личные данные, внутренние URL и конфиденциальные конфигурации. Для ссылок на закрытые ресурсы используй только сведения, которые владелец проекта разрешил раскрывать.

**Важно:** статус `VERIFIED` ставится только после фактического выполнения проверок с записанным результатом. Предположение или запланированная проверка не считаются подтверждением.
